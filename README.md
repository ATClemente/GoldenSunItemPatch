# GoldenSunItemPatch
ROM Hack of the GBA Golden Suns

Increases the base drop rate of all unique and rare items by 8 times. Items excluded are things like the sleep bomb, oil drop, etc. The Lost Age also has a patch that fixes the Random Number Generation. Patch was made using this editor tool: https://www.romhacking.net/utilities/613/

https://goldensun.fandom.com/wiki/Category:Monsters_that_drop_unique_items

https://goldensun.fandom.com/wiki/Category:Monsters_that_drop_rare_items

Patched ROMs are compatible with saves made in a base ROM. No need to start a new playthrough.

My favorite ROM patching tool: 

https://www.marcrobledo.com/RomPatcher.js/
